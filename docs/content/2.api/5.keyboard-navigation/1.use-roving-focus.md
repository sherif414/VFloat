---
title: useRovingFocus
description: Manages physical DOM focus across an ordered list using roving tabindex.
---

`useRovingFocus` implements the WAI-ARIA roving `tabindex` pattern. It manages physical DOM focus across an item list, assigning `tabindex="0"` to the active item and `tabindex="-1"` to all others. Arrow keys, Home, End, and PageUp/PageDown shift DOM focus directly to target items.

Implements the [`NavigationTarget`](/api/overview/types#navigationtarget) protocol for seamless integration with auxiliary composables like [`useTypeahead`](/api/keyboard-navigation/use-typeahead).

## Type

```ts
function useRovingFocus(node: FloatingNode, options: UseRovingFocusOptions): UseRovingFocusReturn;

type RovingEntryFocusMode = "entry-index" | "last-focused";

interface UseRovingFocusOptions {
  elementsList: MaybeRefOrGetter<Array<HTMLElement | null>>;
  containerEl?: MaybeRefOrGetter<HTMLElement | null>;
  activeIndex?: Ref<number>;
  entryIndex?: MaybeRefOrGetter<number | null | undefined>;
  entryFocusMode?: RovingEntryFocusMode;
  orientation?: MaybeRefOrGetter<"vertical" | "horizontal" | "both">;
  loop?: MaybeRefOrGetter<boolean>;
  pageSize?: MaybeRefOrGetter<number>;
  rtl?: MaybeRefOrGetter<boolean>;
  enabled?: MaybeRefOrGetter<boolean>;
  focusOnHover?: MaybeRefOrGetter<boolean>;
  focusDisabledElements?: MaybeRefOrGetter<boolean>;
  openOnArrowKeyDown?: boolean | ((event: KeyboardEvent) => boolean);
  onSelect?: (index: number, event: KeyboardEvent) => void;
  onActiveIndexChange?: (index: number) => void;
  onEnter?: (index: number, event: KeyboardEvent) => boolean | void;
  onExit?: (index: number, event: KeyboardEvent) => boolean | void;
}

interface UseRovingFocusReturn extends NavigationTarget {
  readonly activeIndex: Readonly<Ref<number>>;
  readonly tabStopIndex: Readonly<Ref<number>>;
  setActiveIndex: (index: number) => void;
  reset: () => void;
  focusIndex: (target: NavigationTargetValue, options?: NavigationTargetOptions) => void;
  getTabindex: (index: number) => 0 | -1;
}
```

## Options

| Name                    | Type                                                       | Default          | Notes                                                                                                                                                                       |
| ----------------------- | ---------------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `elementsList`          | `MaybeRefOrGetter<Array<HTMLElement \| null>>`             | **Required**     | The list of HTML element references representing navigable elements.                                                                                                        |
| `containerEl`           | `MaybeRefOrGetter<HTMLElement \| null>`                    | Floating panel   | Container receiving keyboard and pointer events and used for RTL detection. Defaults to `node.refs.floatingEl`.                                                             |
| `activeIndex`           | `Ref<number>`                                              | `undefined`      | Controlled active index ref.                                                                                                                                                |
| `entryIndex`            | `MaybeRefOrGetter<number \| null \| undefined>`            | First enabled    | Default entry item holding `tabindex="0"` when idle. Set `-1` for widgets that start with no initial highlight.                                                             |
| `entryFocusMode`        | `RovingEntryFocusMode`                                     | `"last-focused"` | Whether sequential tab entry restores `"last-focused"` (default / WAI-ARIA APG) or resets to `"entry-index"`.                                                               |
| `orientation`           | `MaybeRefOrGetter<"vertical" \| "horizontal" \| "both">`   | `"vertical"`     | Direction of navigation.                                                                                                                                                    |
| `loop`                  | `MaybeRefOrGetter<boolean>`                                | `false`          | When `true`, navigation wraps around at boundaries.                                                                                                                         |
| `pageSize`              | `MaybeRefOrGetter<number>`                                 | `10`             | Number of items jumped on `PageUp` and `PageDown`.                                                                                                                          |
| `rtl`                   | `MaybeRefOrGetter<boolean>`                                | Auto-detected    | Whether layout follows Right-to-Left reading order. Automatically detected from `containerEl`.                                                                              |
| `enabled`               | `MaybeRefOrGetter<boolean>`                                | `true`           | When `false`, keyboard listeners are inactive.                                                                                                                              |
| `focusOnHover`          | `MaybeRefOrGetter<boolean>`                                | `false`          | When `true`, moving the pointer over an item moves DOM focus and the active index to that item (with `preventScroll: true`). Crucial for menus and submenus.                |
| `focusDisabledElements` | `MaybeRefOrGetter<boolean>`                                | `false`          | Allows disabled items to receive focus for APG discoverability (`onSelect` will not fire on disabled items).                                                                |
| `openOnArrowKeyDown`    | `boolean \| ((event: KeyboardEvent) => boolean)`           | `false`          | When `true` (or predicate returns `true`), pressing `ArrowDown` or `ArrowUp` on the anchor opens the floating element and moves focus into the list. Static (non-reactive). |
| `onSelect`              | `(index: number, event: KeyboardEvent) => void`            | `undefined`      | Callback fired on Enter or Space keydown on active enabled item.                                                                                                            |
| `onActiveIndexChange`   | `(index: number) => void`                                  | `undefined`      | Callback fired when active item index changes.                                                                                                                              |
| `onEnter`               | `(index: number, event: KeyboardEvent) => boolean \| void` | `undefined`      | Callback fired on enter intent (e.g. ArrowRight in LTR) for opening submenus. Return `false` to avoid calling `event.preventDefault()`.                                     |
| `onExit`                | `(index: number, event: KeyboardEvent) => boolean \| void` | `undefined`      | Callback fired on exit intent (e.g. ArrowLeft in LTR) for closing submenus. Return `false` to avoid calling `event.preventDefault()`.                                       |

## Returns

| Name             | Type                                                                         | Notes                                                                                                                                                      |
| ---------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activeIndex`    | `Readonly<Ref<number>>`                                                      | Index of the currently focused item (-1 when unfocused / idle).                                                                                            |
| `tabStopIndex`   | `Readonly<Ref<number>>`                                                      | Index of the element that currently holds `tabindex="0"`.                                                                                                  |
| `focusIndex`     | `(target: NavigationTargetValue, options?: NavigationTargetOptions) => void` | Polymorphic navigation method. Accepts an index, `"reset"`, or directional keywords (`"next"`, `"prev"`, `"first"`, `"last"`, `"page-up"`, `"page-down"`). |
| `setActiveIndex` | `(index: number) => void`                                                    | Sets active index without focusing the DOM element. Pass `-1` to reset active focus.                                                                       |
| `reset`          | `() => void`                                                                 | Resets activeIndex and focus history back to initial conditions.                                                                                           |
| `getTabindex`    | `(index: number) => 0 \| -1`                                                 | Returns `0` if `index === tabStopIndex`, otherwise `-1`. Bind to `:tabindex`.                                                                              |

## Details

### Opening on Arrow Keys

According to the WAI-ARIA APG Menu Button pattern, pressing `ArrowDown` or `ArrowUp` while keyboard focus is on the anchor button opens the menu popup and places initial focus on the first or last menu item respectively.

Setting `openOnArrowKeyDown: true` (or providing a custom predicate function) enables this behavior directly:

- **`ArrowDown`**: Opens the floating element (`node.open.value = true`) and moves DOM focus to the first enabled item.
- **`ArrowUp`**: Opens the floating element (`node.open.value = true`) and moves DOM focus to the last enabled item.
- **Dynamic Element Mounting**: If the floating list is rendered conditionally via `v-if="node.open.value"`, `useRovingFocus` stages the entry intent (`"first"` or `"last"`), pre-computes `tabStopIndex` so items mount with `tabindex="0"`, and automatically focuses the target element once mounted in the DOM.
- **Custom Predicate**: Pass a callback `(event: KeyboardEvent) => boolean` to conditionally allow or suppress opening based on modifier keys, target element, or application state.
- **Static Option**: Unlike reactive options, `openOnArrowKeyDown` is static and evaluated once at composable invocation.

## Example

```vue
<script setup lang="ts">
import { shallowRef } from "vue";
import { useFloatingNode, useRovingFocus } from "v-float";

const items = ["Profile", "Account Settings", "Billing", "Logout"];
const anchorEl = shallowRef<HTMLElement | null>(null);
const floatingEl = shallowRef<HTMLElement | null>(null);
const elementsList = shallowRef<Array<HTMLElement | null>>([]);

const node = useFloatingNode({ anchorEl, floatingEl });

const { activeIndex, getTabindex, focusIndex } = useRovingFocus(node, {
  elementsList,
  orientation: "vertical",
  loop: true,
  openOnArrowKeyDown: true,
});
</script>

<template>
  <button ref="anchorEl" type="button" @click="node.open.value = !node.open.value">Options</button>

  <div v-if="node.open.value" ref="floatingEl" role="menu" class="menu">
    <button
      v-for="(item, idx) in items"
      :key="item"
      :ref="(el) => (elementsList[idx] = el as HTMLElement | null)"
      role="menuitem"
      :tabindex="getTabindex(idx)"
      :class="{ focused: activeIndex === idx }"
      @click="focusIndex(idx)"
    >
      {{ item }}
    </button>
  </div>
</template>
```
